# 도메인 역할 정리

## Word

>`Word`: 워들에서 사용하는 5글자 영어 단어를 표현하는 VO

- 입력값이 null이 아니고, 5글자 영문자인지 검증
- 대문자로 들어온 단어를 소문자로 정규화
- 정답 단어와 제출 단어를 비교해 타일 결과 생성
- 초록색, 노란색, 회색 판정 규칙을 담당
- 중복 문자가 있을 때 정답에 포함된 개수만큼만 노란색으로 표시되도록 처리
- `Word`는 단어 하나의 유효성과 비교 규칙만 책임

---

## GameBoard

> `GameBoard`: 한 판의 게임 진행 상태를 관리하는 도메인 객체

- 플레이어 ID와 게임 ID를 보관
- 제출된 답안의 채점 결과를 순서대로 기록
- 사용한 기회 수를 계산
- 최대 제출 기회 관리
- 정답을 맞췄는지 여부를 관리
- 응답 제출 가능한 상태인지 판단
- 이미 종료된 게임에 제출하려 하면 도메인 예외를 발생
- 정답 단어, 게임 종료 시각, 닉네임은 서비스가 필요한 동작 시점에 전달
- `GameBoard`는 게임의 현재 상태와 종료 조건만을 판단하는 중심 객체다.

---

## WordRepository

> `WordRepository`: 도메인에서 필요한 단어를 조회하고 저장하는 포트

- 게임 생성 서비스가 영속된 단어와 ID를 조회할 수 있도록 한다.
- 도메인은 단어 저장 방식과 분리된다.
- `WordRepositoryImpl`이 JPA 저장소로 이 계약을 구현한다.
