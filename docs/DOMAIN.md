# 도메인 역할 정리

## Word

>`Word`: 워들에서 사용하는 5글자 영어 단어를 표현하는 VO

- 입력값이 null이 아니고, 5글자 영문자인지 검증
- 대문자로 들어온 단어를 소문자로 정규화
- 정답 단어와 제출 단어를 비교해 타일 결과 생성
- 초록색, 노란색, 회색 판정 규칙을 담당
- 중복 문자가 있을 때 정답에 포함된 개수만큼만 노란색으로 표시되도록 처리
- `Word`는 단어 하나의 유효성과 비교 규칙만 책임

---

## GameBoard

> `GameBoard`: 한 판의 게임 진행 상태를 관리하는 도메인 객체

- 정답 단어를 보관
- 제출된 답안의 채점 결과를 순서대로 기록
- 사용한 기회 수를 계산
- 최대 제출 기회 관리
- 정답을 맞췄는지 여부를 관리
- 응답 제출 가능한 상태인지 판단
- 이미 종료된 게임에 제출하려 하면 도메인 예외를 발생
- `GameBoard`는 게임의 현재 상태와 종료 조건만을 판단하는 중심 객체다.

---

## WordDictionary

> `Dictionary`: 정답 후보 단어 목록에서 실제 정답을 선택하는 도메인 객체

- `WordEntity`를 통해 전체 단어 목록 가져옴
- 전달받은 seed를 기준으로 정답 단어를 선택
- 선택된 문자열을 `Word` 객체로 변환
- `Dictionary`는 단어 저장소의 구현 방식에는 의존하지 않음

---

## WordRepository

> `WordEntity`: 도메인에서 필요한 단어 목록 조회 인터페이스

- 도메인 객체가 단어 목록의 저장 위치를 몰라도 되게 만듬
- `Dictionary`가 인프라 구현체에 직접 의존하지 않도록 경계 생성
- 현재 구현에서는 `WordsImpl`이 `words.txt`를 읽어 이 계약을 만족
- `WordEntity` 자체는 도메인 규칙을 실행하지 않고, 단어 목록을 제공하는 인터페이스 역할만 가짐
