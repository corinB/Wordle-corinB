# 미션 - 워들

## 1. 서비스 개요

사용자가 웹 브라우저에서 매일 제공되는 5글자 영어 단어를 최대 6번 안에 맞히는 서비스이다.

사용자는 게임 결과를 저장하고, 이전 플레이 기록과 통계를 확인할 수 있다.

---

## 2. 기능적 요구사항

### 2.1 회원 기능

#### 회원가입

- 사용자는 아이디와 비밀번호를 입력하여 회원가입할 수 있다.
- 아이디는 중복될 수 없다.
- 비밀번호는 암호화하여 저장한다.

#### 로그인

- 사용자는 아이디와 비밀번호로 로그인할 수 있다.
- 로그인한 사용자만 플레이 기록을 저장할 수 있다.
- 로그인 상태를 유지할 수 있다.

#### 로그아웃

- 사용자는 현재 로그인 상태를 종료할 수 있다.

---

### 2.2 워들 게임

#### 게임 시작

- 사용자는 웹 페이지에서 오늘의 워들 게임을 시작할 수 있다.
- 게임은 6행 5열 격자로 표시한다.
- 사용자는 5글자 영어 단어를 최대 6번까지 입력할 수 있다.

#### 정답 선정

- 정답은 DB에 존재하는 단어여야 한다.
- 정답은 매일 변경된다.
- 모든 사용자는 같은 날짜에 동일한 정답을 제공받는다.
- 정답의 인덱스는 다음 계산식으로 결정한다.

```text
(현재 날짜 - 2021년 6월 19일) % 전체 단어 개수
```

- 날짜 계산은 서버 시간을 기준으로 한다.

#### 답안 입력

- 사용자는 키보드 또는 화면 키보드를 이용하여 답안을 입력할 수 있다.
- 답안은 5글자 영어 단어여야 한다.
- 대소문자를 구분하지 않는다.
- 입력된 단어는 소문자로 변환하여 처리한다.
- 유효하지 않은 단어는 시도 횟수에 포함하지 않는다.
- 유효하지 않은 단어가 입력되면 오류 메시지를 표시한다.

#### 답안 판별

입력한 단어와 정답의 알파벳 및 위치를 비교한다.

- 글자와 위치가 모두 일치하면 초록색 타일 `🟩`로 표시한다.
- 글자는 존재하지만 위치가 다르면 노란색 타일 `🟨`로 표시한다.
- 정답에 존재하지 않는 글자는 회색 타일 `⬜`로 표시한다.

#### 중복 문자 처리

- 동일한 문자가 여러 번 입력된 경우 정답에 존재하는 문자 개수만큼만 초록색 또는 노란색으로 표시한다.
- 정답에 존재하는 개수를 초과한 문자는 회색으로 표시한다.
- 위치가 일치하는 문자를 먼저 초록색으로 판별한다.
- 남은 문자를 기준으로 노란색 여부를 판별한다.

#### 게임 진행

- 답안을 제출할 때마다 현재 시도 결과를 화면에 추가한다.
- 이전 시도 결과는 게임이 끝날 때까지 유지한다.
- 이미 입력한 알파벳의 판별 결과를 화면 키보드에도 표시한다.
- 초록색, 노란색, 회색 순서로 우선순위를 적용한다.

#### 게임 종료

다음 조건 중 하나를 만족하면 게임을 종료한다.

- 사용자가 정답을 맞힌 경우
- 사용자가 6번의 기회를 모두 사용한 경우

게임 종료 후 다음 정보를 표시한다.

- 성공 또는 실패 여부
- 사용한 시도 횟수
- 오늘의 정답
- 플레이 결과
- 다음 문제까지 남은 시간

---

### 2.3 일일 게임 제한

- 사용자는 하루에 하나의 오늘의 워들 문제를 플레이할 수 있다.
- 이미 완료한 게임을 다시 시작할 수 없다.
- 페이지를 새로고침하거나 다시 로그인해도 게임 상태가 유지되어야 한다.
- 진행 중인 게임이 있다면 마지막 상태부터 이어서 플레이한다.

---

### 2.4 플레이 기록 저장

게임이 종료되면 다음 정보를 저장한다.

- 사용자 식별자
- 플레이 날짜
- 정답 단어
- 성공 여부
- 사용한 시도 횟수
- 입력한 답안 목록
- 각 답안의 판별 결과
- 게임 시작 시간
- 게임 종료 시간

#### 기록 저장 조건

- 로그인한 사용자의 기록만 저장한다.
- 동일한 사용자와 날짜에 대한 기록은 하나만 저장한다.
- 이미 완료된 기록은 수정할 수 없다.
- 게임이 진행 중인 경우 현재 시도 상태를 저장한다.

---

### 2.5 플레이 기록 조회

사용자는 자신의 이전 플레이 기록을 조회할 수 있다.

기록 목록에는 다음 정보를 표시한다.

- 플레이 날짜
- 성공 또는 실패 여부
- 사용한 시도 횟수
- 정답 단어

사용자는 특정 기록을 선택하여 상세 결과를 확인할 수 있다.

상세 화면에는 다음 정보를 표시한다.

- 입력한 답안
- 각 답안의 타일 결과
- 최종 정답
- 성공 여부
- 시도 횟수

---

### 2.6 플레이 통계

사용자는 자신의 플레이 통계를 확인할 수 있다.

통계에는 다음 정보를 포함한다.

- 전체 플레이 횟수
- 성공 횟수
- 실패 횟수
- 정답 성공률
- 현재 연속 성공 일수
- 최장 연속 성공 일수
- 평균 시도 횟수
- 시도 횟수별 성공 분포

---

## 3. 비기능적 요구사항

### 3.1 실행 환경

- 백엔드는 JDK 25에서 실행할 수 있어야 한다.
- 웹 브라우저를 통해 서비스를 이용할 수 있어야 한다.
- 프로그램 종료를 위해 `System.exit()`를 호출하지 않는다.

---

### 3.2 데이터 정합성

- 하나의 사용자에게 동일한 날짜의 게임 기록이 중복 저장되지 않아야 한다.
- 게임 결과 저장 중 오류가 발생하면 일부 데이터만 저장되지 않도록 한다.
- 게임 완료 기록과 통계 데이터가 일치해야 한다.
- 서버에서 정답과 시도 횟수를 검증한다.
- 클라이언트가 전달한 성공 여부를 그대로 신뢰하지 않는다.

---

### 3.3 보안

- 비밀번호는 평문으로 저장하지 않는다.
- 인증되지 않은 사용자가 다른 사용자의 기록을 조회할 수 없어야 한다.
- 사용자는 자신의 기록만 조회할 수 있다.
- 정답은 게임 종료 전 클라이언트에 노출하지 않는다.
- 요청값에 대한 검증을 수행한다.

---

### 3.5 성능

- 서버 시간 기준 매일 정답 단어를 캐싱한다.
- 기록 목록은 페이지 단위로 조회할 수 있어야 한다.
- 불필요한 데이터베이스 조회를 최소화한다.

---

### 3.6 테스트

- JUnit 5와 AssertJ를 이용하여 테스트한다.
- 게임 판별 로직에 단위 테스트를 작성한다.
- 중복 문자 판별 규칙을 테스트한다.
- 일일 정답 선정 로직을 테스트한다.
- 게임 종료 조건을 테스트한다.
- 기록 저장과 중복 저장 방지를 테스트한다.
- 사용자별 기록 조회 권한을 테스트한다.
- 컨트롤러와 화면 표시 로직보다 도메인 및 서비스 테스트에 집중한다.
